# Aesthetic Body — сайт салона красоты

Сайт на React + TypeScript + Vite: главная (`index.html`), «Обучение» (`obuchenie/index.html`) и «Портфолио» (`portfolio/index.html`) — отдельные HTML-страницы с общими шапкой, подвалом и формой записи. Стили: CSS Modules и токены в `src/styles/tokens.css`. Без UI-китов, Tailwind и анимационных библиотек.

## Запуск

Нужен Node.js 18+.

```bash
npm install
```

```bash
npm run dev
```

Откроется на http://localhost:5173.

```bash
npm run build
```

Проверяет типы (`tsc --noEmit`) и собирает статику в `dist/`.

```bash
npm run preview
```

Локальный просмотр собранной версии.

`dist/` можно выложить на любой статический хостинг (Nginx, Netlify, Vercel, S3 и т. п.).

## Где менять контент

| Что | Файл |
|---|---|
| Название, SEO-описание, домен, телефон, адрес, e-mail, режим работы, соцсети, ссылка на политику, часы для слотов записи | `src/config/site.ts` |
| Услуги и цены — общий прайс сайта и Telegram-бота | `bot/src/catalog.ts` (иконки и описания направлений — `src/data/services.ts`) |
| Отзывы (сейчас демо-данные) | `src/data/reviews.ts` |
| Главное фото (hero) и галерея «Наша атмосфера» на главной | `src/data/gallery.ts` + файлы в `public/images` |
| Портфолио | `src/data/portfolio.ts` |
| Обучение: школа, стоимость, отзыв, фото | `src/data/training.ts` (описание процедуры берётся из услуги «Лазерная эпиляция») |
| Пункты меню и адреса страниц | `src/config/navigation.ts` |
| Цвета, шрифты, отступы | `src/styles/tokens.css` |
| Текст политики конфиденциальности | `public/privacy.html` |

Пустая строка в `site.ts` означает «не задано»: такая строка в подвале не выводится, а соцсеть без ссылки не показывается.

SEO-теги (`title`, `description`, `canonical`, Open Graph, Twitter, `theme-color`) и JSON-LD `BeautySalon` собираются из `site.ts` при сборке (плагин в `vite.config.ts`). В JSON-LD попадают только заполненные поля без заглушек.

### Фотографии

Каждое фото лежит в `public/images` в трёх форматах и нескольких ширинах: `имя-ширина.avif|webp|jpg`, например `about-room-960.jpg`. В `src/data/gallery.ts` указываются `base` (путь без ширины и расширения), список ширин, исходные `width`/`height` и `alt`.

## Подключение онлайн-записи

Готовый приёмник заявок — Telegram-бот в папке [`bot/`](bot/README.md): заявки с сайта приходят администратору в Telegram вместе с записями из бота, а занятое время не даётся дважды.

Скопируйте `.env.example` в `.env` и укажите адрес API:

```
VITE_BOOKING_API_URL=https://api.example.com/booking
```

После изменения переменной пересоберите проект (`npm run build`) или перезапустите `npm run dev`.

**Контракт** (`src/api/booking.ts`):

- Метод `POST`, заголовок `Content-Type: application/json`.
- Тело:

```json
{
  "name": "Анна",
  "phone": "+79123456789",
  "serviceId": "nails-gel",
  "serviceTitle": "Маникюр: Маникюр с покрытием гель-лаком",
  "mode": "slot",
  "date": "2026-11-20",
  "time": "14:30",
  "consent": true
}
```

  - `phone` в формате E.164;
  - `serviceId` — `id` услуги из `src/data/services.ts` либо `<id направления>:any`, если клиент записался на направление и услугу подберёт мастер;
  - `serviceTitle` — название услуги для администратора;
  - `mode` — `slot` (запись на выбранные дату и время) или `callback` (заявка без даты: администратор перезвонит и согласует время; `date` и `time` не передаются);
  - `date` в формате ISO `YYYY-MM-DD`, `time` в формате `HH:MM` (только для `slot`; онлайн-запись открыта на `bookingDaysAhead` дней, это значение должно совпадать с `BOOKING_DAYS_AHEAD` бота).
- Любой ответ 2xx считается успехом: пользователь видит «Спасибо! Мы получили вашу заявку и свяжемся с вами для подтверждения».
- Не-2xx, сетевая ошибка или таймаут (15 с) показывают понятную ошибку с кнопкой повтора; введённые данные сохраняются. Если сервер вернул JSON `{ "message": "…" }`, пользователь видит этот текст (например, «Это время уже занято…»).
- Сервер должен разрешать CORS для домена сайта.

**Если переменная не задана**, заявка никуда не отправляется. Форма честно сообщает «Онлайн-запись пока не подключена. Позвоните нам» с телефоном из конфига, а в консоль браузера пишется `console.info` о демо-режиме.

Защита от ботов: скрытое honeypot-поле; заполненные им заявки не отправляются. Повторная отправка блокируется, пока идёт запрос.

## Структура

```
src/
  api/booking.ts        отправка заявки
  components/           секции страницы
  components/ui/        Button, Icon, Modal, Lightbox, Picture, Reveal
  config/               настройки сайта и меню
  context/              открытие формы записи из любой кнопки
  data/                 услуги, отзывы, фото
  hooks/                фокус-ловушка, блокировка прокрутки, активная секция, появление, свайп
  lib/                  маска телефона, валидация, слоты времени, типографика
  styles/               токены, шрифты, глобальные стили
public/
  fonts/                Cormorant Garamond и Manrope (latin + cyrillic, SIL OFL)
  images/               фотографии
```
