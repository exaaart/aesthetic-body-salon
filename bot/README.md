# Telegram-бот записи Aesthetic Body

Бот принимает записи на процедуры по прайс-листу салона, отправляет заявки администратору на подтверждение и напоминает клиентам о визите. Он же принимает заявки с формы сайта.

## Что умеет

**Клиент:**
- «Записаться»: направление → услуга → вариант цены (первичное посещение или последующие сеансы, длительность массажа) → дата → свободное время → имя → телефон (кнопкой «Отправить мой номер» или текстом) → подтверждение.
- «Прайс-лист»: все услуги с ценами.
- «Мои записи»: предстоящие записи со статусом и кнопкой отмены.
- «Контакты»: адрес, телефон, часы работы.
- Сообщение, когда администратор подтвердил или отклонил запись.
- Напоминание за сутки до подтверждённой записи.

**Администратор** (в чате `ADMIN_CHAT_ID`, можно в группе):
- Карточка каждой новой заявки (из Telegram и с сайта) с кнопками «Подтвердить» и «Отклонить».
- Сообщение, если клиент отменил запись.
- `/bookings` — список предстоящих записей.

Свободное время считается с учётом длительности процедуры, рабочих часов, уже занятых записей (`CAPACITY` клиентов одновременно) и минимального запаса до начала (`LEAD_MINUTES`). Одно и то же время нельзя занять дважды, в том числе одновременно из бота и с сайта.

## Запуск

Нужен Node.js 22.9+ и сервер, где бот будет работать постоянно (VPS, домашний ПК).

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Установите зависимости:

```bash
npm install
```

3. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN`.
4. Соберите и запустите:

```bash
npm run build
```

```bash
npm start
```

5. Узнайте ID чата администратора: напишите боту `/id` в личном чате (или добавьте бота в группу администраторов и отправьте `/id` там). Впишите число в `ADMIN_CHAT_ID` и перезапустите бота.

Для постоянной работы на сервере используйте менеджер процессов, например `pm2 start dist/index.js --name salon-bot --node-args="--env-file=.env"`, или systemd.

## Прайс-лист

Цены и длительности — в `src/catalog.ts`. Источник — обсуждение «ПРАЙС» в группе ВКонтакте, картинки от 5 марта 2024. Длительность лазерных комплексов и чистки с масками в прайсе не указана — стоят оценки с пометкой `TODO`, уточните их. После правки выполните `npm run build` и перезапустите бота.

## Заявки с сайта

Бот слушает `POST /booking` на порту `HTTP_PORT` (по умолчанию 8787). Чтобы форма сайта отправляла заявки в бот:

1. Сделайте порт доступным из интернета по HTTPS (например, через Nginx: `https://api.ваш-домен/booking` → `http://127.0.0.1:8787/booking`).
2. В `.env` бота укажите домен сайта в `ALLOWED_ORIGINS`.
3. На сайте в `.env` укажите `VITE_BOOKING_API_URL=https://api.ваш-домен/booking` и пересоберите сайт.

Ответы: `201` — заявка принята и отправлена администратору; `400` — ошибка в данных; `409` — время занято; `429` — слишком много заявок с одного адреса. В теле ошибки — `{ "message": "…" }`, сайт показывает этот текст пользователю. Заявки с сайта приходят администратору с пометкой «с сайта»; подтверждать их клиенту нужно звонком — у сайта нет чата в Telegram.

## Данные

Записи хранятся в `data/bookings.json` (путь задаётся `DATA_FILE`). Файл перезаписывается атомарно. Делайте его резервную копию. Черновики незавершённых записей хранятся в памяти и сбрасываются при перезапуске — клиенту достаточно нажать «Записаться» заново.

## Проверка

```bash
npm test
```

Тесты прогоняют полный сценарий записи, подтверждение и отмену, защиту от двойной записи и HTTP-приём заявок — без сети и без токена (Telegram API подменяется).
