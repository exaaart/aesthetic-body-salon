# Материалы обратной связи заказчика для сайта Aesthetic Body

Распакуйте папку `docs/` в корень репозитория сайта. В результате в проекте должен появиться путь `docs/client-feedback/`. Затем откройте Claude Code из корня проекта и передайте ему содержимое файла `docs/client-feedback/CLAUDE_CODE_PROMPT.md`.

## Что внутри

| Файл | Назначение |
|---|---|
| `01-home-hero-replace-heading.png` | Главный экран: заменить заголовок цитатой с автором |
| `02-home-section-restore-old-copy.png` | Главная: восстановить прежний текст в этом блоке |
| `03-portfolio-keep-slogan.png` | Портфолио: сохранить слоган «Самое красивое лицо в мире — ваше» в нижнем CTA |
| `04-training-remove-marked-elements.png` | Обучение: убрать отмеченные оранжевыми стрелками элементы |
| `05-booking-form-fix.png` | Запись: добавить альтернативу записи без выбора даты/времени |
| `06-photo-add-to-portfolio.png` | Фотография, которую нужно добавить в портфолио |
| `07-next-photo/` | Папка для ещё одной фотографии, которая не прикрепилась к сообщению |

**Важно:** первые пять файлов — скриншоты-референсы, их нельзя публиковать как изображения сайта. Шестой файл — фотография для самой галереи; Claude Code должен скопировать её в реальную папку публичных изображений проекта. Седьмую фотографию нужно отдельно положить в `07-next-photo/`, когда она будет доступна.

Перед запуском убедитесь, что папка `docs/client-feedback/` находится внутри того же проекта, который открыт в Claude Code.
